# 카페 키오스크 스마트 오더 시스템

음료와 베이커리를 선택하고 장바구니, 매장 이용·테이크아웃, 할인, 모의 결제, 영수증 발급을 체험하는 2인 팀 Java 콘솔 프로젝트입니다.

## 실행 방법

JDK 21 이상이 필요합니다. 외부 라이브러리 의존성은 없습니다. IntelliJ IDEA에서는 프로젝트를 열고 `src`를 Sources Root로 지정한 후 `kiosk.KioskApp.main()`을 실행합니다.

터미널에서는 저장소 루트에서 다음을 실행합니다.

```sh
javac -encoding UTF-8 -d out src/kiosk/*.java
java -cp out kiosk.KioskApp
```

## 기능 및 시연

- 음료 3종과 베이커리 3종을 조회합니다. 음료별 온도, 샷, 우유, 당도 옵션을 제공합니다.
- 같은 상품·옵션은 수량을 합치며, 장바구니에서 수량 변경과 삭제를 지원합니다.
- 주문 전체에 매장 이용 또는 테이크아웃을 선택합니다.
- 시연용 학생 할인은 10%입니다. `CAFE1000` 쿠폰은 1,000원 할인입니다. 주문당 하나의 할인을 적용합니다.
- 카드 승인과 현금 결제를 모의 처리합니다. 현금 부족 시 장바구니를 유지합니다. 성공 시 주문번호와 영수증을 출력합니다. 주문번호는 프로그램 실행 중에만 유지됩니다.

## 객체지향 설계

| 원리 | 적용 |
|---|---|
| 은닉성 | `Cart`가 내부 목록을 보호하고 `CartItem`이 수량을 검증합니다. |
| 상속성 | `Drink`와 `Bakery`가 `MenuItem`의 상품명과 가격 관리를 재사용합니다. |
| 다형성 | 화면은 `MenuItem.options()`를 호출해 상품별 옵션을 조회합니다. |
| 추상성 | `OrderService`는 `DiscountPolicy`와 `PaymentMethod`를 통해 할인과 결제를 처리합니다. |

`src/kiosk`에는 콘솔 화면, 상품 및 옵션, 장바구니, 할인, 결제, 주문 클래스가 들어 있습니다. 초안의 음료별 하위 클래스는 옵션 구성을 생성자로 받는 `Drink`로 통합했습니다. 같은 동작을 공유하는 음료의 메뉴와 추가금은 `MenuCatalog`에서 변경할 수 있습니다.

## 팀 역할 및 AI 활용

- 팀원 1 (이름 입력) — 메뉴·옵션, 콘솔 화면, 이용 방식 시연
- 팀원 2 (이름 입력) — 장바구니, 할인, 결제, 주문 확정 시연
- 공동 — 클래스 다이어그램, 통합 테스트, 코드 검토 및 발표 준비
- ChatGPT 활용 수준 4단계 — 팀 기획을 바탕으로 초기 코드와 README를 생성했습니다. 팀의 실제 검토와 수정 이력은 진행 후 기록합니다.
